
# Exercise 3 – First and Last Elements

## Description
A Python program that asks the user to enter a list of integers and creates a new list containing only the first and last elements of the original list.

The program includes input validation to handle invalid entries and a function that handles empty lists.

## How to Run
Open the terminal in the project folder and run:

```bash
python main.py
```

## Concepts Practiced
- Python lists and indexing
- Functions and return values
- For loops and while loops
- Input validation
- Exception handling (try/except)
- Main guard (`if __name__ == "__main__":`)
